# 🌦️ Weather App (React + Vite)

A modern, responsive weather application built using React and Tailwind CSS that provides real-time weather data with dynamic UI and smooth animations.

## 🚀 Features

* 🌡️ Current weather details (temperature, humidity, wind, pressure, feels like)
* 📅 5-day forecast with horizontal scroll UI
* 🔍 City-based search functionality
* 🎨 Dynamic background based on weather & day/night
* 🌧️ Animated weather effects (rain, clouds, snow, stars, sun)
* ✨ Glassmorphism UI design
* 📱 Fully responsive design

## 🛠️ Tech Stack

* React (Vite)
* Tailwind CSS
* OpenWeatherMap API

## ⚙️ Setup

1. Clone the repo:

```
git clone https://github.com/your-username/weather-app.git
```

2. Install dependencies:

```
npm install
```

3. Add API key in `.env`:

```
VITE_WEATHER_API_KEY=your_api_key
```

4. Run:

```
npm run dev
```
